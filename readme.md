# 📚 Personal Library & Reading Tracker CLI

## 📌 Project Overview

Personal Library & Reading Tracker is a Python-based command-line application designed to manage a personal book collection and track reading progress.

This project is developed as part of the Python Full Stack Development major project at Webskitters Academy.

## 🎯 Project Objectives

- Manage personal book collections.
- Track reading progress.
- Organize books by genre and reading status.
- Store book information using JSON.
- Apply Object-Oriented Programming concepts.
- Practise modular programming and exception handling.

## ✨ Planned Features

1. Add a new book.
2. View all books.
3. Filter books by status or genre.
4. Update reading progress.
5. Mark books as finished.
6. Remove books.
7. Search books by title or author.
8. View reading statistics.
9. Save and load book data automatically.

## 🛠️ Technologies Used

- Python
- Object-Oriented Programming (OOP)
- JSON
- Git & GitHub

## ⚙️ Installation & Setup

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Navigate to the project folder

```bash
cd Personal-lib-reading-tracker-cli
```

### 3. Create a virtual environment

```bash
python -m venv venv
```

### 4. Activate the environment (Windows)

```bash
venv\Scripts\activate
```

### 5. Install dependencies

```bash
pip install -r requirements.txt
```

### 6. Run the application

```bash
python main.py
```
